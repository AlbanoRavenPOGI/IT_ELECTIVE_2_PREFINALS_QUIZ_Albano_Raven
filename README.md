# IT_ELECTIVE_2_PREFINALS_QUIZ_Albano_Raven

Prefinals Quiz submission for IT Elective 2. This is an ASP.NET Core MVC portfolio application that showcases my class projects, quizzes, homework, and exams from my GitHub profile (`AlbanoRavenPOGI`).

## Features

* Built with **ASP.NET Core MVC** (Controllers, Models, and Views)
* Simple login system using session storage
* Portfolio grid displaying repositories with thumbnails and categories
* Project details page with direct GitHub repository links
* Working comment section on each project page
* Responsive UI with word-wrapping for long repository names
